ПЛАГИН «ВОРОТА» ДЛЯ AUTOCAD (ворота, забор, потолок)
===========================

Файлы
  vorota.lsp          — для AutoCAD 2021 и новее (UTF-8)
  vorota_cp1251.lsp   — для AutoCAD 2020 и старше (кодировка Windows-1251)
  Нужен полный AutoCAD (не LT): 3D-тела в LT не строятся.

Установка
  1. Команда APPLOAD (ЗАГПРИЛ).
  2. Выбрать файл vorota.lsp -> «Загрузить».
     Чтобы грузился всегда: в том же окне «Автозагрузка» (Startup Suite) -> «Добавить».

Запуск: ВОРОТА (или VOROTA)
  Ширина ворот, мм           <4000>
  Высота ворот, мм           <2000>
  Толщина металла, мм        <2>
  Узор 1-9: 1-Ромб 2-Треугольник 3-Квадрат 4-Соты 5-Восьмигранник
            6-Ёлочка 7-Кирпич 8-Алмаз 9-Кристалл
  Размер ячейки, мм          (свой для каждого узора)
  Петелька, мм               <2>   — перемычка на линии гиба
  Прорез между петельками,мм <10>
  Угол отгиба лепестков      <35>
  Соединение листов:         1-болты М6 через лапки сзади / 2-сварка лапок (без отверстий)
  Остальное по умолчанию?    1-да / 0-нет (металл между ячейками 20, поле по краю 20, лапка 20, лист, 3D, рама)
  Enter — принять значение в <скобках>.

Стыки листов НЕ ВИДНЫ
  Большая площадь делится на листы так, что край листа идёт по середине
  полосы металла между ячейками (зигзагом/ступенькой, вокруг целых ячеек).
  Спереди стык выглядит как обычная полоса узора.
  На каждом отрезке стыка — лапка 20 мм, загибается на 90° НАЗАД.
  Лапки соседних листов встают спина к спине — их стягивают болтами М6
  (отверстие в лапке) или проваривают. Спереди крепежа не видно.

Что получится в чертеже
  * Сверху — 3D-модель ворот: листы с толщиной, лепестки отогнуты (изгибы),
    лапки на стыках, рама из трубы 60x40.
    Посмотреть: -ВИД (-VIEW) -> ЮЗизо, ВИЗСТИЛИ -> Концептуальный.
  * Снизу — развёртки, каждая на своём листе (рамка листа — слой LIST).
    Слой REZ — ВСЁ режется:
      - лучи от центра ячейки к углам — сквозной рез (лепестки);
      - стороны ячейки — пунктир-прорез с петельками (размеры спрашивает команда) — гиб лепестка;
      - край листа на стыке: лапки, пунктир — гиб лапки 90° назад;
      - контур листа с перемычками 2 мм (держат деталь в листе);
      - отверстия Ø6,5 в лапках под болты М6 (если выбраны болты).
    Для лазера: отключить слои LIST, TEXT, VOROTA_3D, VOROTA_RAMA, выгрузить в DXF.

Сборка
  1. Вырезать, выломать листы из перемычек.
  2. Загнуть лапки на стыках на 90° назад.
  3. Отогнуть лепестки наружу на заданный угол (по умолчанию 35°), все одинаково.
  4. Соседние листы стянуть болтами М6 через лапки (или проварить лапки),
     ровное поле по внешнему краю прикрутить/приварить к раме.
  Удлинить ворота: запустить ВОРОТА с новой шириной — узор сквозной через стыки.
