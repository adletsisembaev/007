## Версия 1.1 (15.11.2026), по результатам первой проверки в SketchUp

- Плагин подтверждён в SketchUp: окно открывается, `CABINET_900_WALL` создан.
- Русский интерфейс (`locales/ru.json`), переключатель RU/EN.
- Новая палитра материалов: цвета, текстуры, материалы модели, свой цвет.
  Старый выбор цвета не реагировал: системное окно выбора цвета, судя по всему,
  не открывается во встроенном браузере SketchUp, а существующий материал
  блокировал смену цвета.
- Угловой шкаф с фальш-панелью.
- Исправлено: после создания шкаф больше не становится «изменяемым»; смена
  верхнего на нижний при изменении запрещена.

## Версия 1.2 (15.11.2026)

- Материал цокольной планки (по умолчанию «как фасады»).
- Направление текстуры для каждого материала.
- RAL Classic, «Мои материалы» (текстуры с компьютера, папки, свои цвета/коды
  например Sirca). Каталогов Egger/Sirca нет — объяснено пользователю.
- Отступы ХДФ задней стенки от краёв корпуса (по умолчанию 2 мм).
- Кромка; экспорт раскроя и сметы в CSV (`geometry/cut_list.rb`,
  `geometry/report.rb`, `sketchup/exporter.rb`).

## Что ещё не проверено

Работа плагина в настоящем SketchUp. Нужно пройти чек-лист из 12 пунктов в
конце `docs/FEATURES.md` и прислать результаты или ошибки из
**Window → Ruby Console**.

## Возможные следующие шаги

- Г-образный угловой шкаф.
- Шкаф под мойку.
- Экспорт раскроя в CSV: размеры заготовок уже есть в атрибуте
  `cut_size_mm` каждой детали.
- Шкаф под технику.
- Комбинация «ящик над дверью».
- Кромка, вычитаемая из размеров деталей.
- Интерактивная вставка шкафа курсором.
