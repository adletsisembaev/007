# Возможности, ограничения и статус проверки (версия 1.0.0)

## Реализовано

**Интеграция с SketchUp**
- Регистрация через `SketchupExtension`, установка из `.rbz`.
- Меню **Extensions → Kitchen Cabinet Designer**.
- Тулбар с иконками 24 и 32 px, который запоминает своё состояние.
- Пункт контекстного меню **Edit Selected Cabinet**.
- Уникальное пространство имён `KitchenCabinetDesigner`, без глобальных
  переменных, наблюдателей и фоновых процессов.

**Шкафы**
- Нижние и верхние шкафы. Каждый шкаф — отдельный компонент
  `CABINET_<ширина>_<BASE|WALL>`, каждая деталь — отдельная группа с понятным
  именем.

**Корпус**
- Боковины на всю высоту, дно и крыша между ними.
- Верх нижнего шкафа: крышка, две царги с настраиваемой шириной или открытый.
- Задняя стенка:
  - накладная;
  - вставная, с настраиваемым отступом;
  - вставная в паз. Паз строится как настоящий вырез в боковинах, дне и
    крыше; при нулевом отступе он превращается в четверть;
  - без задней стенки.
- Толщина задней стенки, глубина паза, зазор на дне паза и запас по ширине
  настраиваются.
- Полки с равными промежутками и настраиваемым отступом от переда. При
  вставных дверях полки автоматически начинаются за дверью.

**Опоры нижнего шкафа**
- Варианты: ножки, ножки с цокольной планкой, две цокольные планки, без опор.
- Высота цоколя, отступ и толщина планки, диаметр и положение ножек
  настраиваются.
- У широких шкафов добавляется средняя пара ножек.
- Подъём всего шкафа (`elevation`).

**Верхний шкаф**
- Высота подвеса, отступ от стены.
- Монтажная шина: ставится за задней стенкой и проверяется на то, хватает ли
  места.

**Фасады**
- Накладные и вставные, одна или две двери.
- Толщина, зазор между фасадами, зазоры по каждому краю, удлинение вверх и
  вниз, утопление вставных фасадов.

**Ящики**
- От 1 до 8 ящиков. Высоты фасадов автоматические или ручные; есть смешанный
  вариант `140; 0; 0`.
- Короб из пяти деталей.
- Боковой зазор под направляющие.
- Автоматическая глубина по стандартной длине направляющей, ограничение
  «глубина корпуса − 30 мм».
- Зазоры короба настраиваются, высота короба автоматическая или ручная.

**Материалы**
- Пять материалов: корпус, фасады, задняя стенка, короба ящиков, ножки и
  шина.
- Существующие материалы модели используются без изменений. Новые создаются
  только если реально нужны.

**Параметричность**
- Параметры хранятся в атрибутах компонента, поэтому шкаф можно изменить и
  после повторного открытия файла.
- При перестроении шкаф остаётся у стены.
- Можно обновить все копии или только выбранный шкаф.

**Надёжность**
- Полная проверка параметров с понятными сообщениями до начала построения.
- Одна операция на одно действие, поэтому Undo и Redo работают одним шагом.
- При ошибке операция отменяется, и недостроенная геометрия не остаётся.

**Диалог**
- Разделы по ТЗ и превью вида спереди.
- Последние параметры запоминаются отдельно для нижних и верхних шкафов.
- Тексты вынесены в `locales/en.json`: для русского языка достаточно
  добавить `ru.json` с теми же ключами. Язык выбирается по языку SketchUp.

## Известные ограничения

1. **Угловой шкаф, шкаф под мойку, под встроенную технику и «свой» шкаф** не
   реализованы. В списке они помечены «(planned)», при попытке создать
   выводится «Not implemented yet».
2. **Ящики только у нижних шкафов.** Комбинации в одном шкафу (ящик над
   дверью) пока нет.
3. **Фурнитура не моделируется:** петли, направляющие, ручки. Ножки — простые
   цилиндры.
4. **Одна схема корпуса:** боковины на всю высоту. Вариант «дно под
   боковинами» не реализован.
5. **Нет кромки:** толщина кромки не вычитается из размеров деталей.
6. **Вставка только по расчёту:**
   - новый шкаф ставится либо к стене по красной оси модели, либо справа от
     выделенного шкафа той же категории;
   - интерактивной вставки курсором нет;
   - при повороте модели стена «по умолчанию» не определяется автоматически.
7. **Список материалов модели** не обновляется сам. Если материал добавлен
   вручную, нажмите **Refresh material list**. Так сделано намеренно, чтобы
   не держать наблюдателей.
8. **Превью** показывает только вид спереди, без 3D. Ножки на нём
   изображены прямоугольниками.
9. **Русский перевод** не включён, но подготовлен (см. выше).
10. **Раскрой (cut list)** не экспортируется. Размеры заготовок уже записаны
    в атрибут `cut_size_mm` каждой детали.

## Чек-лист ручной проверки в SketchUp 2024

Пройдите его один раз после установки. Ошибки смотрите в **Window → Ruby
Console**.

1. [ ] Расширение видно в Extension Manager, версия 1.0.0.
2. [ ] Есть меню **Extensions → Kitchen Cabinet Designer** и тулбар с иконкой.
   После перезапуска SketchUp тулбар восстанавливается.
3. [ ] Диалог открывается и закрывается; повторное нажатие кнопки выводит его
   на передний план.
4. [ ] Шкаф по умолчанию создаётся. Инструментом Tape Measure: ширина 600,
   корпус 720, цоколь 100, глубина корпуса 560, фасад 18 мм впереди.
5. [ ] В Outliner видна иерархия `CABINET_600_BASE → CARCASS / SUPPORTS /
   FRONTS`.
6. [ ] **Ctrl+Z** удаляет шкаф целиком, включая новые материалы. **Ctrl+Y**
   возвращает его.
7. [ ] Вставная задняя стенка в паз: у боковин видна канавка, детали — солиды
   (Entity Info → Solid Group).
8. [ ] Нижний шкаф с ящиками 3 шт. и `140;0;0`: фасады 140 / 287 / 287 мм,
   коробы не пересекаются.
9. [ ] Верхний шкаф с шиной: вставная стенка с отступом 16, шина за стенкой.
10. [ ] Выделить шкаф → правый клик → **Edit Selected Cabinet** → изменить
    глубину → **Update Selected**: задняя плоскость осталась на месте.
11. [ ] Сохранить модель, закрыть, открыть, выделить шкаф → **Load Selected**:
    параметры загрузились.
12. [ ] Ввести ширину `0` → ошибка у поля, шкаф не создаётся, модель не
    меняется.
